# TextLab

Analyze real documents, inspect word frequencies, and generate an offline report.
This workshop connects a small Python program with useful documentation and
reproducible execution.

## Two different outputs

**The analysis report** contains measured word counts from input documents.
**This documentation site** explains how the program works and how to use it.
Rebuilding documentation does not rerun the analysis.
