# Sources and attribution

The input documents are unmodified README snapshots of real Pallets projects:

- [Flask](https://github.com/pallets/flask)
- [Click](https://github.com/pallets/click)
- [Jinja](https://github.com/pallets/jinja)

See `sources.json` in the repository for exact source commits, retrieval times
and SHA-256 hashes. The original BSD-3-Clause notices are in `third_party/`.

[CodeRefinery's workflow-management lesson](https://coderefinery.github.io/reproducible-research/workflow-management/).
